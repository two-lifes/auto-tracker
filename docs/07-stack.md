# 07. Стек и окружение

Это решения, а не код. Если меняете стек, правьте этот документ и `decisions.md`, остальные документы от стека не зависят.

## Рекомендованный стек
| Область | Решение | Почему |
|---|---|---|
| Язык | Python 3.12+ | Зрелая экосистема для Telegram-ботов |
| Библиотека Bot API | aiogram 3.x | Асинхронная, активно поддерживается, есть встроенные пошаговые сценарии (FSM) |
| БД | SQLite | Одного пользователя хватает с запасом, бэкап сводится к копии файла |
| Доступ к БД и миграции | ORM с версионированными миграциями | Требование НФТ о миграциях |
| Планировщик напоминаний | Внутри процесса бота, задания и журнал хранятся в БД | Переживает перезапуски, без дублей |
| Получение обновлений | Long polling | Не нужны домен и TLS |
| Тесты, линтер | pytest, ruff | Стандарт для Python |
| Экспорт | CSV (UTF-8 с BOM для Excel), XLSX по желанию | Корректная кириллица (US-15) |

Конкретные версии зависимостей фиксируются в репозитории при этапе 0.

## Окружение VPS
- ОС Linux (уточнить дистрибутив и версию у владельца перед этапом 0).
- Развёртывание: Docker Compose (один сервис, том для данных) **или** systemd-служба с виртуальным окружением. Выбор фиксируется в `decisions.md` на этапе 0, по умолчанию Docker Compose.
- Каталог данных: БД, фото, бэкапы, логи. Расположение вынесено в конфигурацию.
- Бэкапы запускаются по расписанию системы (cron или systemd timer) либо внутри бота. Выбор фиксируется на этапе бэкапов.

## Конфигурация (переменные окружения)
- токен бота;
- белый список Telegram ID;
- путь к каталогу данных;
- часовой пояс по умолчанию;
- уровень логирования;
- параметры внешней копии бэкапов (если используется).

## Структура репозитория (ожидаемая)
- `CLAUDE.md`: правила для Claude CLI.
- `docs/`: эти документы, `progress.md`, `decisions.md`.
- `README.md`: запуск локально, развёртывание и обновление на VPS, восстановление из бэкапа.
- Исходный код, тесты, миграции, пример конфигурации.

## Данные, которые нужно получить у владельца до этапа 0
- Токен бота от @BotFather.
- Свой Telegram ID.
- Дистрибутив VPS, есть ли на нём Docker, способ доступа (SSH).
- Куда класть внешнюю копию бэкапов.
