# 05. UX диалогов бота

## Общие правила
- Язык русский, тон нейтральный и краткий. Без лишних эмодзи, допускается по одному эмодзи на кнопку меню.
- Основное управление кнопками. Команды дублируют главные действия.
- В каждом пошаговом сценарии есть «Пропустить» (для необязательных шагов), «Назад» и «Отмена».
- Перед сохранением показывается сводка с кнопками «Сохранить», «Изменить», «Отмена».
- После сохранения бот подтверждает действие кратко, с ключевыми значениями.
- Ошибка ввода не прерывает сценарий: бот объясняет ожидаемый формат и повторяет вопрос.
- Длинные списки разбиваются на страницы по 5–10 элементов, переход кнопками «‹ ›».
- Необратимые действия (удаление, отключение) всегда требуют подтверждения.

## Главное меню (постоянная клавиатура)
Над меню показывается строка «🚗 <активный профиль> · <текущий пробег> км».
- ➕ Запись
- 🛣 Пробег
- 📜 История
- 🔔 Напоминания
- 📷 Фото
- 🚗 Авто (профили; переключение появляется, если профилей больше одного)
- ⚙️ Настройки

## Команды
/start, /menu, /help, /cancel, /km (пробег), /add (запись), /history, /last (когда последний раз), /remind, /photos, /car, /export, /settings.

## Форматы ввода
- **Пробег:** только цифры, пробелы допустимы («152300», «152 300»).
- **Дата:** «сегодня», «вчера», ДД.ММ, ДД.ММ.ГГГГ. Есть кнопки «Сегодня» и «Вчера». Дата в будущем для записи обслуживания не допускается.
- **Сумма:** число с копейками через точку или запятую, валюта по умолчанию из настроек.
- **Интервал напоминания:** отдельные шаги «км», «время», «предупредить за», у каждого кнопка «Не задавать».

## Ключевые сценарии
1. **Новая запись.** Тип, категория (кнопки с частыми категориями, «Все категории», «Своя»), описание, дата, пробег, стоимость, место, позиции (опционально, цикл «Добавить ещё / Готово»), фото (цикл, «Готово»), сводка.
2. **Пробег.** Ввод числа, подтверждение «+N км с <дата>». Сработавшие напоминания приходят следом.
3. **История.** Фильтры (категория, тип, период), лента, карточка записи. В карточке кнопки «Фото», «Изменить», «Удалить».
4. **Когда последний раз.** Выбор категории, ответ одной карточкой.
5. **Фото.** Выбор: галерея по меткам или фото записей за период. Выдача альбомами. У каждого альбома кнопка перехода к записи.
6. **Напоминания.** Список с ближайшей точкой срабатывания. Кнопки «Создать», «Из шаблона». В карточке «Изменить», «Пауза/Возобновить», «Удалить».
7. **Сообщение напоминания.** Текст, условие, текущее состояние («осталось 800 км / 12 дней»), кнопки «Выполнено», «Отложить», «Отключить».
8. **Фото вне сценария.** Кнопки «К последней записи (<кратко>)», «К новой записи», «В галерею».
9. **Профили.** Список, «Создать», «Сделать активным», «Изменить», «В архив».

## Тексты-образцы (тон)
- Подтверждение: «Сохранено: замена масла ДВС, 12.10.2026, 152 300 км, 6 450 ₽.»
- Ошибка: «Пробег не может быть меньше текущего (152 300 км). Введите число или нажмите «Отмена».»
- Напоминание: «🔔 Октавия: замена масла. Осталось 500 км или 14 дней (что раньше).»

## Восстановление контекста
Если бот перезапустился посреди сценария, по следующему сообщению владельца сценарий продолжается с того же шага или владельцу предлагается «Продолжить / Начать заново».
