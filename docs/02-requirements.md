# 02. Функциональные требования

Нумерация FR-x используется в сценариях, плане этапов и журнале прогресса.

## FR-1. Доступ
- FR-1.1. Бот обслуживает только Telegram ID из белого списка в конфигурации.
- FR-1.2. Сообщения от остальных игнорируются или получают один нейтральный отказ. Попытки доступа пишутся в лог.

## FR-2. Профили автомобилей
- FR-2.1. Создание профиля. Обязательные поля: название (например, «Октавия»), начальный пробег. Необязательные: марка, модель, год, госномер, VIN, тип двигателя, дата покупки, заметка.
- FR-2.2. Редактирование любого поля профиля.
- FR-2.3. Активный профиль. Все операции выполняются в его контексте, его название видно в главном меню.
- FR-2.4. Переключение активного профиля. Если профиль один, выбор не предлагается.
- FR-2.5. Архивирование: профиль скрыт из выбора, данные сохранены. Полное удаление возможно только с двойным подтверждением.
- FR-2.6. При первом запуске бот предлагает создать первый профиль.

## FR-3. Пробег
- FR-3.1. Ввод показания одометра с датой (по умолчанию сегодня).
- FR-3.2. Пробег в профиле не убывает со временем. Меньшее значение на более позднюю дату отклоняется с объяснением. Исправление ошибочного показания делается через редактирование.
- FR-3.3. Текущий пробег равен последнему по дате показанию. Он берётся как из ввода пробега, так и из записей обслуживания.
- FR-3.4. История показаний и средний пробег в месяц, если данных достаточно.
- FR-3.5. Периодический запрос пробега. Включается в настройках, частота настраивается. Нужен для напоминаний по пробегу.

## FR-4. Записи обслуживания
- FR-4.1. Поля записи: тип (замена, ТО, ремонт, диагностика, прочее), категория, описание, дата (по умолчанию сегодня), пробег (по умолчанию текущий, можно пропустить), стоимость работ и запчастей, место или сервис, заметка.
- FR-4.2. Позиции записи (необязательно): наименование детали или материала, производитель, артикул, количество, цена.
- FR-4.3. Категории. Встроенный справочник (масло ДВС, масляный фильтр, воздушный фильтр, салонный фильтр, топливный фильтр, свечи, тормозные колодки, тормозные диски, тормозная жидкость, антифриз, ГРМ, АКПП/МКПП масло, шины/сезонная смена, АКБ, щётки, прочее). Владелец может добавлять свои категории.
- FR-4.4. К записи прикрепляются фото, от 0 до N.
- FR-4.5. Запись можно просмотреть, отредактировать и удалить (с подтверждением).
- FR-4.6. Создание записи с категорией пересчитывает связанные интервальные напоминания (FR-7.5).

## FR-5. Фото
- FR-5.1. Фото можно привязать к записи обслуживания или к галерее профиля (документы, СТС, страховка, повреждения, прочее).
- FR-5.2. Принимаются фото в обычном виде (Telegram сжимает) и как файл (оригинальное качество). Формат при выдаче совпадает с форматом при загрузке.
- FR-5.3. У фото могут быть подпись и метка галереи.
- FR-5.4. Выдача фото: все фото записи, галерея профиля по метке, фото за период. Несколько фото отправляются альбомами.
- FR-5.5. Удаление фото с подтверждением.
- FR-5.6. Фото, присланное вне сценария, не теряется: бот спрашивает, куда его прикрепить (к последней записи, к новой записи, в галерею).

## FR-6. История и поиск
- FR-6.1. Лента последних записей с постраничной навигацией.
- FR-6.2. Фильтры: категория, тип, период, сочетание фильтров.
- FR-6.3. Текстовый поиск по описанию, заметкам и позициям.
- FR-6.4. «Когда последний раз»: по категории показываются дата, пробег, сколько прошло дней и км, стоимость.
- FR-6.5. Сводка расходов за период, итог и разбивка по категориям.

## FR-7. Напоминания
- FR-7.1. Виды условий:
  - по дате (однократно);
  - по пробегу (однократно, при достижении X км);
  - по интервалу: каждые N км, и/или каждые M дней/месяцев, начиная с заданной точки или с последней записи категории;
  - комбинированное условие «что наступит раньше».
- FR-7.2. Заблаговременное предупреждение (необязательно): за N км и/или за N дней.
- FR-7.3. У напоминания есть текст, профиль, необязательная категория и статус (активно, на паузе, выполнено, отключено).
- FR-7.4. При срабатывании отправляется сообщение с кнопками: «Выполнено» (создаёт запись с предзаполненной категорией), «Отложить» (на N дней или N км), «Отключить».
- FR-7.5. Для интервального напоминания с категорией новая запись этой категории сдвигает следующую точку срабатывания от даты и пробега записи.
- FR-7.6. Напоминания можно посмотреть списком, отредактировать, поставить на паузу, возобновить и удалить.
- FR-7.7. Напоминания по дате приходят в настраиваемое время суток в часовом поясе владельца.
- FR-7.8. Напоминания по пробегу проверяются при каждом обновлении пробега.
- FR-7.9. Шаблоны быстрого создания, например «масло каждые 10 000 км или 12 мес.». Их можно изменить до сохранения.

## FR-8. Экспорт
- FR-8.1. Экспорт записей, пробега и напоминаний профиля в CSV (или XLSX) файлом в чат.
- FR-8.2. Архив фото профиля. Если архив больше лимита отправки Telegram, он разбивается на части.

## FR-9. Настройки
- Часовой пояс, валюта по умолчанию, время доставки напоминаний, частота запроса пробега, единица пробега (км).

## FR-10. Служебное
- FR-10.1. Команда «Помощь» с кратким описанием возможностей.
- FR-10.2. Владелец получает в бот сообщение о критических ошибках (без технических подробностей, только факт и время).
